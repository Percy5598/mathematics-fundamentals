# Mathematics Fundamentals

A structured, practical journey through mathematics for data science, statistics, econometrics, machine learning, and decision science.

## Objectives

- Build mathematical intuition before memorizing formulas.
- Learn to solve problems manually and verify results with Python.
- Develop strong foundations in calculus, linear algebra, probability, and statistics.
- Understand the mathematical foundations of machine learning and economic decision-making.
- Build a collection of reproducible Jupyter notebooks and independent exercises.

## Learning Method

Each topic follows this sequence:

1. Intuition and conceptual explanation
2. Visual or geometric interpretation
3. Mathematical notation and formulas
4. Step-by-step manual calculations
5. Python implementation
6. Visualization
7. Real-world application
8. Independent exercises

## Curriculum

1. Arithmetic and Algebra
2. Functions and Graphs
3. Calculus
4. Linear Algebra
5. Probability
6. Statistics
7. Optimization
8. Information and Decision Theory
9. Econometrics and Time Series
10. Mathematics for Machine Learning

## Technology

- Python
- Jupyter Notebook
- NumPy
- pandas
- Matplotlib
- SciPy
- SymPy

## Guiding Principle

Understand the mathematics first. Use code to verify, explore, and apply it.
